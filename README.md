\# Документация к программам обработки числовых последовательностей



В данном репозитории представлены 4 скрипта на Python для выполнения базовых операций над списками целых чисел, вводимых в одну строку через пробел.



\## Описание работы скриптов



\### 1. Описательная статистика (`statistics.py`)

Программа принимает строку чисел и вычисляет метрики без использования встроенных функций поиска экстремумов.

\* \*\*Алгоритм\*\*: Написан ручной однопроходный цикл, который одновременно подсчитывает количество элементов, аккумулирует сумму, а также сравнивает текущее значение с текущими минимумом и максимумом.

\* \*\*Защита от ошибок\*\*: Если строка пустая, программа не уходит в ошибку деления на ноль, а сразу выводит `Нет данных`.

\* \*\*Вывод\*\*: `Количество Сумма Минимум Максимум Среднее(2 знака после точки)`



\### 2. Независимое преобразование (`transform.py`)

Программа демонстрирует принцип неизменяемости (immutability) исходных структур данных.

\* \*\*Алгоритм\*\*: С помощью генератора списков создается абсолютно новый массив. Отрицательные числа заменяются их модулями при помощи `abs()`. Исходный список остается нетронутым.

\* \*\*Вывод\*\*: Две независимые строки с исходным и измененным списками.



\### 3. Максимальные позиции (`positions.py`)

Поиск всех мест вхождения самого большого числа в последовательности.

\* \*\*Алгоритм\*\*: Сначала скрипт находит максимальное значение в цикле, после чего с помощью функции `enumerate()` собирает все его индексы. Так как обход идет слева направо, индексы автоматически сортируются по возрастанию.

\* \*\*Вывод\*\*: Список индексов в формате `\[idx1, idx2, ...]` или `Нет данных`.



\### 4. Фильтрация по варианту №12 (`variant.py`)

Скрипт обрабатывает числа по индивидуальному критерию: \*\*Положительные чётные числа\*\* (`x > 0` и `x % 2 == 0`).

\* \*\*Алгоритм\*\*: Из входной строки отбираются только подходящие элементы. Для расчета итоговых метрик применяются встроенные функции `sum()` и `sorted()`.

\* \*\*Вывод\*\*: `\[результат] количество сумма \[отсортированный\_результат]`

\## Тестирование и контрольные примеры



\### Тест 1: Контрольный ввод из задания

\* \*\*Входные данные:\*\* `-8 -3 0 6 6`



| Скрипт | Ожидаемый результат | Примечание |

| :--- | :--- | :--- |

| `statistics.py` | `5 -1 -8 6 -0.20` | Сумма: -5, Среднее: -5/5 = -0.20 |

| `transform.py` | Исходный: `\[-8, -3, 0, 6, 6]` <br> Новый: `\[8, 3, 0, 6, 6]` | Исходный массив сохранен |

| `positions.py` | `\[3, 4]` | Максимум 6 находится на 3 и 4 позициях |

| `variant.py` | `\[6, 6] 2 12 \[6, 6]` | Подходят только две шестерки |



\### Тест 2: Пустой ввод

\* \*\*Входные данные:\*\* \*(просто нажатие Enter)\*



| Скрипт | Ожидаемый результат |

| :--- | :--- |

| `statistics.py` | `Нет данных` |

| `transform.py` | Исходный: `\[]` <br> Новый: `\[]` |

| `positions.py` | `Нет данных` |

| `variant.py` | `\[] 0 0 \[]` |



\### Тест 3: Альтернативный непустой набор (Все отрицательные)

\* \*\*Входные данные:\*\* `-2 -4 -7 -2`

\* \*\*Цель теста:\*\* Показать поведение программ, когда под критерии Варианта 12 не подходит ни одно число, а также проверить работу с дубликатами максимумов для отрицательных чисел.



| Скрипт | Ожидаемый результат | Примечание |

| :--- | :--- | :--- |

| `statistics.py` | `4 -15 -7 -2 -3.75` | Максимум корректно определен как `-2` |

| `transform.py` | Исходный: `\[-2, -4, -7, -2]` <br> Новый: `\[2, 4, 7, 2]` | Все элементы стали положительными |

| `positions.py` | `\[0, 3]` | Индексы самого большого числа (`-2`) |

| `variant.py` | `\[] 0 0 \[]` | Корректная обработка пустого промежуточного итога |
